# Пользовательские сценарии → экраны

> Для кого: два человека ведут личные финансы. Заходят раз в несколько дней, чаще всего — «как у меня с деньгами в этом месяце».
> Кредиты (вкладка «Кредиты») в этой версии не менялись.

| # | Ситуация | Что хочет понять или сделать | Где | Как |
|---|---|---|---|---|
| С0 | Открыл приложение впервые или токен истёк | Войти | **Страница входа** | логин и пароль → токен в браузере; при любом 401 токен забывается и снова показывается вход. «Выйти» — иконка в шапке. Пользователей заводит владелец сервера: `we-finance set-password <логин>` |
| С1 | Открыл приложение | Сколько пришло за месяц, куда ушло, что осталось | **Главная** | переключатель месяца; итоги по выписке: остаток, доходы, расходы, располагаемый; плашка «Ждут разбора: N»; категории с долями и пометкой «перерасход»; «Доходы по выписке» — пришла ли зарплата |
| С2 | Планирую траты | Что и когда придёт или спишется | **Главная → «Что дальше»** | лента 8 ближайших событий: поступления (+, зелёным) и платежи по кредитам (−) по датам |
| С3 | Смотрю доходы за год | Сколько на руки, сколько налога, что по месяцам | **Доходы → Отчёт** | итоги года, ближайшая выплата, годовой отчёт по месяцам как лист Excel (с итогом), график, выплаты по датам (свёрнуты) |
| С4 | Ухожу в отпуск / заболел | Отметить и увидеть, как изменятся деньги | **Доходы → «Отпуск или больничный»** | окно: вид, с–по → запись → отчёт пересчитан, уведомление «на руки за год: ±N» |
| С5 | Изменились условия, ошибся в данных | Поправить оклад, питание, отпуска, историю | **Доходы → «Актуализировать данные»** | отдельная страница «Мои данные», в меню её нет; «Сохранить» возвращает на отчёт |
| С6 | Обсуждаю повышение / снижение питания | Сколько станет на руки, ничего не меняя | **Доходы → «Что если»** | новые условия с даты → было / станет по месяцам |
| Р1 | Пришла выписка банка | Загрузить и не задвоить | **Расходы → Загрузка** | банк + файл `.xlsx` → новых / дублей / без категории. Повторная загрузка того же файла ничего не задваивает |
| Р2 | Есть операции без категории | Разложить один раз и навсегда | **Расходы → Разбор** | у операции — категория и галочка «Запомнить»: следующие такие же разложатся сами |
| Р3 | Куда ушли деньги | Сумма, доля от располагаемого, цель, перерасход | **Расходы → Месяц** | дерево категорий, клик — подкатегории, ещё клик — операции |
| Р4 | Хочу свои категории и цели | Добавить, переименовать, задать цель в %, удалить | **Расходы → Категории** | системные (Кредит, Доход, Маркетплейсы, Неопределённые) не удаляются |
| Р5 | Переводы себе и платежи по кредиту считаются тратами | Сказать системе, где мои счета | **Расходы → Мои счета** | свой номер, свой счёт, кредитный счёт |
| Р6 | Пришла ли зарплата, как в расчёте | Сверить расчёт с выпиской | **Главная → «Доходы по выписке»**, **Доходы → Отчёт, колонка «Выписка»** | Пришло / Расхождение (сколько) / Не найдено / Нет выписки / Ожидается |
| С7а | Кредит выплачен / заведён по ошибке | Убрать из списка, не потеряв историю | **Кредиты → карточка** | при остатке 0 — подсказка «Кредит выплачен» и «В архив завершённых»; «Удалить кредит» внизу карточки → «Архив → Удалённые»; там «Восстановить». Завершённые учитываются на главной, удалённые — нигде |
| С7 | Думаю взять новый кредит | Какой будет график и переплата | **Калькулятор** | параметры кредита → график или полный расчёт с ЧДП, ничего не сохраняет |
| С8 | Что-то не работает | Состояние сервера | **шестерёнка в шапке → Система** | состояние и версия. Пользователю в обычной работе не нужно, поэтому не в верхних вкладках. Копии данных делает сервер |

Верхние вкладки: **Главная · Доходы · Расходы · Кредиты · Калькулятор**.

Пока backend не умеет эндпоинт «Расходов», экран показывает вымышленный пример с жёлтой плашкой «Пример: сервер этого ещё не умеет» (фолбэк на 404/405). Статус сервера в шапке — человеческими словами: «Всё работает», «База данных недоступна», «Сервер не отвечает».
